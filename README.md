# CodeAlpha Stock Portfolio Tracker

A beginner-friendly Python project developed as part of my CodeAlpha Python Development Internship.

## 📌 Project Overview

The Stock Portfolio Tracker allows users to enter stock symbols and quantities, calculate their investment for each stock, and display the total portfolio investment.

The project also saves the portfolio details in a CSV file for future reference.

## ✨ Features

- Enter stock symbols and quantities
- Calculate investment for each stock
- Display total investment
- Validate available stock symbols
- Save portfolio details to a CSV file
- Simple command-line interface

## 🛠️ Technologies Used

- Python
- Dictionaries
- Loops
- Conditional Statements
- CSV File Handling
- User Input and Output
